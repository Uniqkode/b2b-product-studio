# Rill

Give every irrigation team a clear plan for the next watering cycle.

Plan irrigation around the fields you actually manage. Turn a soil reading and a water budget into the next practical watering window.

## Run

Serve the `dist` folder with any static HTTP server. There is no install or build step for the standalone output. Do not open HTML with file://; localStorage and route behavior need HTTP.
