# Development stages

Each website has a public roadmap separating working code, configuration and future integration. No pilot, production deployment or delivery date is asserted without evidence.

## Fieldwell

### 01. Product foundation — Built

Website, review workspace, source citations, report retention, operational register and downloads are implemented.

### 02. Azure model connection — Ready to configure

Azure OpenAI connector code and configuration checks are implemented. A deployed model, endpoint and server-side credentials are still required.

### 03. Sector data integration — Planned

Connect drone survey uploads and field boundaries; evaluate a crop-specific vision model against labelled observations.

### 04. Reviewed field pilot — Planned

Have agronomists review flagged areas against field inspections and track missed and duplicate observations.

### 05. Production operations — Planned

Implement verified accounts, organization access, audit history, retention controls, monitoring and measured capacity limits before commercial operation.
