Updated 17 November 2026. This notice covers the published website, its browser-local review tools and the optional configured AI service.

Privacy notice

Website sample records are included in the published files. Changes to records, retained reports and optional project briefs are saved in this browser. The sample workspace uses a session flag and does not create a production account. Reset clears this brand’s local data; it does not delete downloaded files or material sent to another service.

Connected analysis sends entered text and selected images only when that action is run. The separately configured server then calls its selected AI provider. Its account, region, access and retention settings must be reviewed before using actual organizational data.

The enquiry form prepares a message for your review. When the destination is GitHub, the submitted issue is public. When a verified contact email is configured, you send the message through your own email application. No message is silently submitted by this static website.

Terms of use

Rill provides an evidence-led software review workflow. Prepared examples explain how a finding relates to a source and a human decision; they are not measured customer results or professional approval. Public sample access is not a secure organizational account.

Published plan definitions are subject to agreed onboarding, processing allowances, live configuration and written commercial terms before paid service. Viewing the website or requesting a walkthrough does not establish a customer contract or an operational guarantee.

The responsible professional or appointed operator must check the evidence and make the decision. A farm operator checks sensor quality and local conditions before any watering decision. This MVP does not control pumps. Do not use the public sample workspace as a confidential system of record.
