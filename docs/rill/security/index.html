SECURITY & DEMO SCOPE

Clarity includes
the limits.

An honest account of the data, login and operational scope of this demonstration. No compliance certification, uptime guarantee or production security claim is implied.

DEMONSTRATION STATUS

Public sample data.
Browser-local changes.
No production backend.

Implementation details
01

Demo access is not authentication

The login page checks publicly documented demo credentials and stores a flag in sessionStorage. Anyone can access the static sample data. Do not use this mechanism to protect confidential records.

02

Your edits stay in this browser

Record changes use localStorage on this origin, under a separate brand key. They are not synchronized to a server or another user. A person with access to the same browser profile can read them.

03

Use sample information only

Do not enter personal data, access codes, confidential contracts, survey documents, security weaknesses or other sensitive operational information. This is a public demonstration.

04

No background integrations

The prototype does not contact sensors, identity providers, cameras, emergency services, banks or business applications. Sample scores are fixture data. Scenario calculators perform transparent arithmetic.

05

Static hosting and external links

GitHub Pages hosts the public files using HTTPS. Images and fonts are served locally with the site. External creator, source and license links open only when clicked. GitHub may process ordinary hosting request information under its own privacy policy.

06

Reset and export

Use “Reset demo data” to clear the current brand’s saved records and session. CSV export downloads the current view. Resetting this browser cannot remove copies of files already downloaded.

07

Before a production pilot

Implement server-side authentication and authorization, tenant isolation, encryption appropriate to the data, audit records, backups, monitoring and an incident process. Validate the actual controls before making any security or certification claim.
