AI TECHNOLOGY

Data, method, evidence and review.

Video is a continuous workload. The system checks frames for defined events, groups repeated detections and sends only the relevant time window for a supervisor to review.

01 / PLANNED MODEL PATH

Defined-event vision detection

Detect the selected gate state or movement event in sampled frames without recognizing identity.

How to evaluate it +

Use authorized labelled clips and evaluate false/missed events by site condition.

02 / PLANNED MODEL PATH

Temporal event grouping

Combine repeated frame observations into one bounded review window.

How to evaluate it +

Measure repeated alerts, incorrectly merged events and clip boundaries.

03 / PLANNED MODEL PATH

Supervisor brief generation

Explain the event rule, time window and evidence reference.

How to evaluate it +

Check timestamps, source references, uncertainty and absence of unsupported identity claims.

COMPUTE CHOICE

Sampled video is the clearest GPU-inference candidate in this collection. Capacity depends on streams × sampled frames per second × model latency. Compare an Azure ML online endpoint with an AKS GPU serving pool, measure both and group events before asking a language model for a brief.
