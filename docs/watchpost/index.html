THE AZURE ARCHITECTURE

Technology with
a defined job.

Video is a continuous workload. The system checks frames for defined events, groups repeated detections and sends only the relevant time window for a supervisor to review.

Planning scenario: 57,024,000 frame checks per month. The capacity model is a planning basis, not current customer traffic.Follow the full processing path
  1. 01

    Azure Machine Learning online endpoints

    Host a trained event-detection model for sampled frames; GPU capacity depends on the chosen model and regional quota.

    Planned integration
  2. 02

    Azure Blob Storage

    Retain authorized event clips and the reviewed time window according to the site’s retention policy.

    Planned integration
  3. 03

    Azure OpenAI in Microsoft Foundry

    Summarize a grouped event and the site rule without identifying a person.

    Connector implemented · configure Azure deployment
  4. 04

    Azure Service Bus

    Deliver a single grouped review item to the supervisor and handle processing failures.

    Planned integration
