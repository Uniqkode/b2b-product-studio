The product roadmap.

The stages below separate implemented software, configuration work and the integrations still needed for a real operational pilot.

AI checks site video for defined events and sends supervisors the relevant clip.

Milestones advance when the relevant code, configuration or pilot evidence is available. No delivery dates or existing pilot customers are claimed.

Read the Azure architecture ↗
  1. 01
    Built

    Product foundation

    Website, review workspace, source citations, report retention, operational register and downloads are implemented.

    Open the working workspace ↗
  2. 02
    Ready to configure

    Azure model connection

    Azure OpenAI connector code and configuration checks are implemented. A deployed model, endpoint and server-side credentials are still required.

    Inspect the Azure connector code ↗
  3. 03
    Planned

    Sector data integration

    Connect an authorized test video source and train/evaluate the defined event detector; implement clip retention and event grouping.

  4. 04
    Planned

    Reviewed field pilot

    Compare grouped events with supervisor review, measure false and missed events, and verify access and retention controls.

  5. 05
    Planned

    Production operations

    Implement verified accounts, organization access, audit history, retention controls, monitoring and measured capacity limits before commercial operation.
